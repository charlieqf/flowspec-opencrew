# 提示词撰写指南：口播人物产品替换模型优先级3

更新时间：2026-05-16  
适用任务：固定机位 9:16 口播视频，替换人物/产品，保持参考图人物、产品、背景、坐姿、机位一致  
优先级3模型：

1. Gemini · `veo-3.1-generate-preview`

模型配置备注：

| 配置 | 说明 |
| --- | --- |
| 分辨率 | 720p / 1080p |
| 成本 | $0.4 / second |
| 定位 | 高真实感复验模型，适合在 Grok / Veo Lite / Wan2.7 已经筛出可用提示词后，用于高质量复跑 |

说明：本指南只聚焦 Gemini 的 `veo-3.1-generate-preview`。它与 `veo-3.1-lite-generate-preview` 同属 Veo 3.1 路线，但成本更高，适合做最终画面质感复验，不建议作为第一轮大规模试错模型。Veo 3.1 标准模型的提示词必须特别强化：产品不能放下、不能换产品、不能把 SRT 当动作、首尾帧不能切镜头、不能直接硬切到尾帧。

## 一、三轮测试反馈回顾

### Round1：最短视频与能力边界测试

目标：大范围测试最短时长、单图、首尾帧、多图参考、图片+音频等模型能力。

总体反馈：

| 项目 | 结论 |
| --- | --- |
| 测试规模 | Dashboard 61 条，49 条有人工评价 |
| 高频问题 | SRT 不准、产品文字不清、镜头不固定、产品不一致、画幅错误、人物不一致、拆包/创造包装 |
| Veo 相关结论 | Veo 具有较好人物真实感和画面控制潜力，但早期首尾帧 4s 路径不支持，后续 8s 路径跑通 |

Veo 3.1 反馈：

| 测试方式 | Round1 反馈 | 对提示词的影响 |
| --- | --- | --- |
| 单图 / 最短时长 | Veo 画面控制较好，但 SRT 不准、产品一致性不稳定。 | 不要依赖模型原生语音，产品一致性必须硬约束。 |
| 首尾帧 4s | 早期返回 `INVALID_ARGUMENT`，当前 use case 不支持。 | 不用 4s 首尾帧作为 Veo 默认策略。 |
| 首尾帧 8s 补跑 | 后续 8s 路径跑通，但出现过渡跳动、组合图风险。 | 首尾帧必须写成“一镜到底自然过渡”，不要把参考图拆成两个镜头。 |
| 声音/SRT | Veo 多次出现吞音或 SRT 不准。 | 声音最终建议外部 TTS，Veo 主要负责画面真实感。 |

Round1 对 Veo 3.1 标准模型的结论：

- Veo 3.1 标准模型可作为真实感候选，但不能大规模无约束调用。
- 4 秒首尾帧路径不稳定，不作为默认策略。
- 如果使用首尾帧，推荐 8 秒或模型支持的固定时长，并明确禁止切镜头/组合图。

### Round2：统一 8 秒测试

目标：统一 8 秒、统一参考图 `1.png` / `2.png` / `3.png`、统一产品“化橘红润肺膏 / 和润膏”，观察更接近生产长度时的稳定性。

Veo 3.1 反馈：

| Case | 反馈 | 对提示词的影响 |
| --- | --- | --- |
| `8s_gemini_veo31_single` | 产品清晰，口型准确，人物准确，但语音不是很准确，有吞音，结尾会把产品放下。 | 单图可用，但必须把“产品始终在手中、胸口以上、正面可见”写为最高优先级。 |
| `8s_gemini_veo31_firstlast` | 产品清晰，人物准确，但语音吞音，会按照画面组合切镜头。 | 首尾帧可用但风险高，必须强调一镜到底、不能组合图片、不能切镜。 |
| `8s_gemini_veo31fast_firstlast` | 与标准 Veo 类似，也有组合图片和切镜头。 | fast 和标准模型共享同类首尾帧风险。 |
| `8s_gemini_veo30_single` | 有莫名字幕，语音吞音。 | 所有 Veo prompt 都必须强禁止字幕、标题、水印和屏幕文字。 |
| `8s_gemini_veo30fast_single` | 产品清晰，但结尾会把产品放下。 | “放下产品”是 Veo 家族共同高风险。 |

Round2 对 Veo 3.1 标准模型的结论：

- 优势：产品较清晰、人物准确、口型准确、画面真实感强。
- 短板：吞音、结尾放下产品、首尾帧组合图/切镜头。
- 生产中不应把 Veo 作为“声画一体最终输出”；更适合画面复刻，声音交给 TTS。

### Round3：最短片段链式拼接测试

目标：从 `1.png` 开始，按模型最短片段生成；每段截取上一段尾帧作为下一段首帧，拼成约 8 到 9 秒视频。

Veo 3.1 反馈：

| Case | 反馈 | 对提示词的影响 |
| --- | --- | --- |
| `round3_chain_gemini_veo31` | 产品文字较清晰，语音有吞字，口型准确，人物准确真实，衔接自然；但第一段后把产品放下，第二段拿出一个完全不一样的产品；最终帧不接近 `3.png`。 | Veo 的产品连续性必须作为最高优先级，不能只写“不要放下”，要写产品位置、手部状态、不能重置场景。 |
| `round3_chain_gemini_veo31_lastFrame_12s_comparison` | 最后一帧接近 `3.png`，但直接跳到尾帧；lastFrame 路径导致总时长变 12.043s。 | 首尾帧会影响时长，且可能硬切到尾帧；如果使用必须明确“连续自然过渡，不硬切”。 |
| `round3_chain_gemini_veo31fast` | 第二段内部服务器错误。 | fast 版本不作为稳定替代；标准模型也应保留失败重试策略。 |

Round3 对 Veo 3.1 标准模型的结论：

- Veo 3.1 标准模型的画面真实感、人物自然度和口型仍然强。
- 最大风险不是人物，而是产品行为：放下产品、换产品、尾帧硬切。
- 它适合做高质量复验，但每段都必须人工检查产品是否连续持有。

默认决策：

## 三、中文提示词撰写指南

### 3.1 通用提示词结构

Veo 3.1 标准模型的提示词建议固定由 9 个部分组成：

1. 任务定义：真实竖屏 9:16 固定机位直播口播。
2. 图片输入说明：输入图必须作为第一帧延续，不是风格参考。
3. 人物锁定：同一人物、同一脸、同一衣服、同一麦克风、同一背景、同一坐姿。
4. 产品连续性：同一产品从第一帧到最后一帧始终在手中。
5. 产品完整性：不能打开、拆开、换包装、放桌面、离开画面。
6. 镜头锁定：一镜到底、无切镜、无组合图、无近景插入。
7. SRT 行为解释：台词只是声音内容，不是动作指令。
8. 声音策略：吞音可接受，最终 TTS；画面稳定优先；不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。
9. 负面约束：无字幕、无水印、无屏幕文字、无额外包装。

### 3.2 中文正向模板：Veo 3.1 单图

用于：Gemini · `veo-3.1-generate-preview`，单图 `1.png` 或上一段尾帧。

```text
请基于输入图片生成一段真实的竖屏 9:16 固定机位直播口播视频。输入图片必须作为视频第一帧延续，不是风格参考。请保持输入图片中的同一位年轻中国女性主播、同一脸部身份、同一发型、同一浅蓝色 T 恤、同一黑色领夹麦克风、同一室内厨房/客厅背景、同一桌面关系、同一坐姿和同一手机机位。

这是一个一镜到底的真实口播镜头，不是产品演示，不是广告剪辑，不是产品特写视频。镜头必须完全锁定：不要推镜、拉镜、摇移、变焦、重构图、镜头晃动、切镜头、蒙太奇、组合图、场景变化、近景插入或产品特写。

主播从第一帧到最后一帧都必须一直拿着同一个化橘红润肺膏 / 和润膏产品盒。产品盒必须完整闭合，正面标签朝向镜头，保持在胸口到下巴之间，始终在主播手中，不能低于画面下边缘，不能放到桌面上，不能离开手，不能离开画面，不能换成另一个产品。

口播文字只表示“要说的话”，不是动作指令。即使台词里出现“拿着看了”“看了”“这个季节”等词，主播也不能低头检查产品，不能把产品放下，不能打开产品，不能演示使用，不能换产品。她只需要保持产品稳定，面对镜头自然说话。

动作必须非常克制：自然眨眼、轻微嘴部运动、轻微头部动作、极小幅度手指稳定调整。保持真实人物比例，不改变衣服、发型、麦克风、背景、光线和产品包装。

禁止字幕、标题、水印、任何屏幕文字、额外中文或英文文字。禁止打开、拆开、撕开、展开、倒出、吃喝、展示内包装、创造额外包装、创造第二个产品。

如果模型生成声音不稳定或吞字，优先保证画面连续、口型自然、产品不变；最终声音会由外部 TTS 替换。音频中不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。

口播内容：
【在这里放入本段 SRT 或口播文本；如果生成 8 秒，SRT 必须补齐 8 秒】
```

### 3.3 中文约束增强：产品连续持有

Veo 3.1 标准模型最重要的风险是放下产品后再重新生成一个不同产品。

```text
产品连续持有最高优先级：
- 产品连续性高于动作丰富度。宁可动作少，也不能放下产品。
- 第一帧中主播手里的产品必须连续保持到最后一帧。
- 产品必须始终在同一只手中或同一持握姿态附近，不能离手、不能放桌面、不能低于胸口、不能出画。
- 不允许在任何片段开始时重新生成一个相似但不同的产品。
- 不允许更换包装颜色、形状、标签方向、产品大小或产品数量。
- 如果输入图是上一段尾帧，必须继续尾帧中的同一产品，不要重置场景。
```

### 3.4 中文约束增强：SRT 不是动作指令

Round3 中 `自己拿着看了` 这类句子可能诱导模型演示动作。

```text
口播文本解释规则：
- SRT 只是主播要说的话，不是动作脚本。
- 不要根据台词执行“看产品、放下产品、拿起产品、打开产品、展示产品”等动作。
- “拿着看了”指口播内容中提到别人自己拿着看，不代表当前主播要低头看或改变产品位置。
- 主播全程面向镜头，自然口播，产品稳定正面展示。
```

### 3.5 中文首尾帧模板：Veo 3.1

只在确实需要最终姿态时使用。默认生产不建议首尾帧。

```text
本视频使用首帧和尾帧参考。首帧是视频开始画面，尾帧只是最终状态参考。请生成一个连续的一镜到底竖屏口播镜头，从首帧自然过渡到尾帧。

不要把首帧和尾帧当成两个不同镜头。不要切镜头，不要闪切，不要组合图片，不要蒙太奇，不要最后一帧硬切到尾帧，不要重置人物、产品、背景或机位。人物、产品、手部位置、背景、光线和机位必须连续一致。

产品必须从首帧到尾帧始终在主播手中，完整闭合，正面可见。过渡到尾帧时也不能把产品放下、打开、换包装、移动到画面外或改变镜头。

如果 lastFrame 路径导致模型倾向生成更长视频，请仍然保持连续口播，不要为了匹配尾帧而制造跳切。
```

### 3.6 中文链式片段模板：Veo 3.1

用于上一段尾帧作为下一段输入。

```text
这是链式口播视频中的一个片段。输入图片是上一段视频截取的最后一帧。本段第一帧必须自然延续输入图片，不能重新生成一个相似但不同的人、产品或背景。

请保持上一段尾帧中的同一主播、同一产品、同一手部位置、同一背景、同一灯光和同一固定机位。产品必须继续保持在手中，完整闭合，正面可见，不能在片段开始时被放下、替换或重新生成。

本段只允许轻微口播动作和自然眨眼。不要为了让画面更丰富而增加新的动作、产品演示、镜头切换或背景变化。
```

## 四、English Prompt Writing Guide

### 4.1 Universal Prompt Structure

Use nine blocks for Veo 3.1 standard prompts:

1. Task definition: realistic vertical 9:16 locked-camera livestream talking-head video.
2. Image role: input image must be continued as the first frame, not used as a style reference.
3. Host lock: same identity, face, clothing, microphone, background, seated posture.
4. Product continuity: the same product remains held from first frame to last frame.
5. Product integrity: no opening, unwrapping, replacing, tabletop placement, or out-of-frame motion.
6. Camera lock: one continuous shot, no cuts, no montage, no combined reference-image shots.
7. SRT interpretation: spoken narration only, not action instructions.
8. Audio strategy: generated audio may be inaccurate; final audio can be TTS. No background music, soundtrack, ambient music, or sound effects; audio may contain speech/voice only.
9. Negative constraints: no subtitles, watermark, on-screen text, or extra packaging.

### 4.2 English Positive Template: Veo 3.1 Single Image

Use for Gemini · `veo-3.1-generate-preview`.

```text
Create a realistic vertical 9:16 locked-camera livestream talking-head video from the supplied image. The supplied image must be continued as the first frame of the video, not used as a style reference. Preserve the exact same young Chinese female host, same face identity, same hairstyle, same powder-blue T-shirt, same black lavalier microphone, same indoor kitchen/living-room background, same table relationship, same seated posture, and same phone-camera position.

This is a single continuous realistic oral presentation shot, not a product demonstration, not an ad montage, and not a product close-up video. The camera must be completely locked: no pan, tilt, dolly, zoom, reframing, camera shake, cuts, montage, combined reference-image shots, scene changes, close-up inserts, or product insert shots.

From the first frame to the last frame, the host must continuously hold the exact same Huajuhong Runfei Gao / Herun Gao product box. The box must stay fully closed and intact, front label facing the camera, between chest and chin height, always in the host's hand. It must never fall below the lower frame edge, never be placed on the table, never leave the hand, never leave the frame, and never be replaced by a different product.

Treat the speech text only as spoken narration, not as action instructions. Even if the line mentions "holding it and looking at it", "looking", or "this season", the host must not look down, inspect the product, put it down, open it, demonstrate usage, or replace it. She only keeps the product steady and speaks naturally to the camera.

Motion must be very restrained: natural blinking, subtle mouth movement, tiny head motion, and minimal finger stabilization only. Keep realistic human proportions. Do not change clothing, hairstyle, microphone, background, lighting, or product packaging.

No subtitles, captions, title text, watermark, on-screen text, or generated Chinese/English text. Do not open, unwrap, tear, unfold, pour, eat, drink, reveal inner packaging, create extra packaging, or create a second product.

If generated audio is unstable or contains swallowed words, prioritize visual continuity, natural lip motion, and unchanged product. Final audio will be replaced with external TTS. No background music, soundtrack, ambient music, or sound effects; audio may contain speech/voice only.

Speech / SRT:
[INSERT SEGMENT SRT OR SPOKEN TEXT HERE; IF THE VIDEO MUST BE 8 SECONDS, PAD THE SRT TO 8 SECONDS]
```

### 4.3 English Constraint Add-on: Continuous Product Holding

```text
Highest-priority continuous product holding rules:
- Product continuity is more important than rich action. Prefer less motion rather than putting the product down.
- The exact product held in the first frame must remain continuously held until the last frame.
- The product must always stay in the same hand or nearly the same holding pose. It must not leave the hand, be placed on the table, fall below chest height, or move out of frame.
- Do not regenerate a similar but different product at the start of any segment.
- Do not change package color, shape, label direction, product size, or product count.
- If the input image is the previous segment's tail frame, continue the exact product visible in that tail frame. Do not reset the scene.
```

### 4.4 English Constraint Add-on: SRT Is Not Action

```text
Speech text interpretation rules:
- The SRT is spoken narration only, not an action script.
- Do not execute actions such as looking at the product, putting it down, picking it up again, opening it, or demonstrating it because of the narration.
- If the script says "holding it and looking at it", it refers to spoken content about someone else; it does not mean the current host should look down or change product position.
- The host faces the camera for the entire segment, speaks naturally, and keeps the product steady and front-facing.
```

### 4.5 English First/Last Frame Template: Veo 3.1

Use only when the final pose is required. Do not use first/last-frame as the default production path.

```text
This video uses a first-frame and last-frame reference. The first frame is the starting image. The last frame is only the final-state reference. Generate one continuous vertical 9:16 locked-camera talking-head shot that naturally transitions from the first frame to the last frame.

Do not treat the first and last frames as two different shots. No cuts, no jump cuts, no image-combination behavior, no montage, no hard cut to the last frame, and no reset of host, product, background, or camera. Host identity, product, hand position, background, lighting, and camera position must remain continuous and consistent.

The product must remain in the host's hand from the first frame to the last frame, fully closed, intact, and front-facing. Do not put it down, open it, replace it, move it out of frame, or change the camera to approach the last frame.

If the last-frame path tends to generate a longer video, still keep the video as a continuous oral presentation. Do not create a jump cut just to match the last frame.
```

### 4.6 English Chained Segment Template: Veo 3.1

```text
This is one segment in a chained talking-head video. The supplied image is the extracted final frame of the previous segment. The first frame of this segment must naturally continue that input image. Do not regenerate a similar but different host, product, or background.

Preserve the exact same host, product, hand position, background, lighting, and locked camera from the previous tail frame. The product must continue to be held in the hand, fully closed, intact, and front-facing. It must not be put down, replaced, or regenerated at the beginning of this segment.

Only subtle mouth movement, natural blinking, and tiny head motion are allowed. Do not add new actions, product demonstrations, camera cuts, or background changes to make the scene more dynamic.
```

## 五、模型级操作建议

### 5.1 推荐输入

| 场景 | 推荐输入 | 说明 |
| --- | --- | --- |
| 默认复验 | 单图 `1.png` | 最稳，避免首尾帧组合图和硬切 |
| 链式复验 | 上一段尾帧作为下一段单图输入 | 比 lastFrame 更适合固定机位连续口播 |
| 需要末帧姿态 | 首帧 + 尾帧 | 只做专项测试，必须接受切镜/时长风险 |
| 声音准确 | 不建议依赖模型原生音频 | 用 TTS 替换最终音轨；不能有背景音乐，只能有人声口播 |

### 5.2 推荐分辨率和成本策略

| 阶段 | 分辨率 | 建议 |
| --- | --- | --- |
| Prompt 验证 | 720p | 用于确认产品是否不放下、人物是否稳定、是否无字幕 |
| 候选复验 | 720p | 对同一 prompt 跑 2 到 3 次，观察稳定性 |
| 最终片段 | 1080p | 只对已通过 720p 验证的片段升级 |
| 成本控制 | $0.4 / second | 避免大规模试错，先用低成本模型筛 prompt |

### 5.3 推荐时长

| 时长 | 建议 |
| --- | --- |
| 4 秒 | 可用于单图短测，但首尾帧历史上不稳定 |
| 8 秒 | 推荐主测试长度，SRT 必须补齐 8 秒 |
| 12 秒对照 | 只保留为 lastFrame 行为观察，不作为默认主线 |
| 90 秒长视频 | 拆成 6 到 8 秒片段，最终 TTS 和拼接 |

### 5.4 必查项

每段生成后必须检查：

- 是否 9:16。
- 是否出现字幕、标题、水印或屏幕文字。
- 产品是否从第一帧到最后一帧都在手中。
- 产品是否同一包装、同一颜色、同一正面标签。
- 是否打开、拆开、露出内包装。
- 是否在段间把产品放下再重新拿起。
- 是否把首尾帧做成切镜或组合图。
- 声音是否吞字；如果吞字，口型是否仍可配 TTS。

### 5.5 硬淘汰规则

直接淘汰：

- 产品放到桌上或离开手。
- 下一段换成不同产品。
- 产品打开、拆开、露出内包装。
- 首尾帧硬切或组合图明显。
- 出现字幕、水印或屏幕文字。
- 人物身份明显变化。
- 固定机位被破坏。
- 原生音频严重吞字且口型无法配 TTS。

## 六、替换人物/替换产品时的提示词变量

```text
{HOST_DESCRIPTION} = 年轻中国女性主播，浅蓝色 T 恤，黑色领夹麦克风，室内厨房/客厅背景

{SRT_TEXT} = 本段口播 SRT，8 秒视频必须补齐 8 秒
```

替换人物时必须改：

- `{HOST_DESCRIPTION}`
- 衣服颜色、发型、麦克风、背景、坐姿
- 禁止改变参考图身份和机位

替换产品时必须改：

- `{PRODUCT_NAME_CN}`
- `{PRODUCT_DESCRIPTION}`
- 包装颜色、形状、标签方向、正面朝向要求
- 禁止旧产品词残留
- 明确“不能放下、不能打开、不能换包装”

## 七、最终推荐工作流

1. 先用 Grok / Veo Lite / Wan2.7 低成本验证提示词。
2. 确认产品不会放下、不会换产品、不会出现字幕后，再用 Veo 3.1 标准模型跑 720p。
3. 720p 至少复跑 2 次，观察是否稳定不放下产品。
4. 只有通过 720p 检查的片段才升级 1080p。
5. 不默认使用首尾帧；如果使用，单独标记为高风险测试。
6. 最终声音使用外部 TTS，Veo 只保画面真实感和自然口型；最终音轨不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。
7. 每段人工检查产品连续性，任何放下/换产品/拆包直接重跑。
