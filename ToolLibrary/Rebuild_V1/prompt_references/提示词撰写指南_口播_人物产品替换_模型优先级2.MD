## 二、Wan2.7-i2v 模型定位

| 维度 | 评价 |
| --- | --- |

| 语音/SRT | 很强，三轮中多次被评价为语音特别准确 |

默认决策：

- 要产品文字清晰：Wan2.7-i2v 优先。
- 要语音准确：Wan2.7-i2v 可优先，但仍要检查包装是否被打开。
- 要长视频稳定拼接：Wan2.7-i2v 可用，但必须锁曝光、锁白平衡、最终建议外部 TTS。
- 不要使用 `wan2.7-r2v` 替代 `wan2.7-i2v`。

## 三、中文提示词撰写指南

### 3.1 通用提示词结构

Wan2.7-i2v 的提示词建议固定由 8 个部分组成：

1. 任务定义：真实竖屏 9:16 固定机位直播口播。
2. 图片输入说明：输入图是第一帧和视觉来源，不是风格参考。
3. 人物锁定：同一人物、同一衣服、同一麦克风、同一背景、同一坐姿。
4. 产品锁定：同一产品包装，完整闭合，正面可见，始终在手中。
5. 镜头锁定：无推拉摇移、无变焦、无切镜、无近景插入。
6. 曝光锁定：亮度、白平衡、肤色、背景颜色和产品颜色不能逐段变暗。
7. 音频/口播约束：音频只驱动口型，不能驱动手部演示或拆包；不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。
8. 负面约束：无字幕、无水印、无新产品、无拆包、无桌面展示。

### 3.2 中文正向模板：Wan2.7-i2v 单图

用于：Wan · `wan2.7-i2v-2026-04-25` 单图 `1.png` 或上一段尾帧。

```text
请基于输入图片生成一段真实的竖屏 9:16 固定机位直播口播视频。输入图片是视频的第一帧和唯一视觉来源，不是风格参考。请延续图片中的同一位年轻中国女性主播、同一张脸、同一发型、同一浅蓝色 T 恤、同一黑色领夹麦克风、同一室内厨房/客厅背景、同一坐姿、同一手机拍摄距离。

主播面对镜头自然口播，动作非常轻微：自然眨眼、轻微头部动作、自然嘴部口播动作、极小幅度手指稳定调整。产品必须是输入图片里的同一个化橘红润肺膏 / 和润膏绿色银色包装盒，完整闭合，正面标签朝向镜头，始终在主播手中，保持在胸口到下巴之间的位置。

产品不能打开、不能拆开、不能撕开、不能露出内包装、不能倒出内容物、不能吃喝、不能放到桌面、不能离开画面、不能换成其他包装、不能生成第二个产品。口播文字只是要说的话，不是动作指令，不要演示产品使用。

画面必须保持竖屏 9:16，固定手机机位，一镜到底。不要推镜、拉镜、摇移、变焦、重构图、镜头晃动、切镜头、蒙太奇、产品特写或场景变化。不要添加字幕、标题、水印、浮动文字或任何额外屏幕文字。

请锁定曝光和白平衡，保持与输入图片一致的亮度、肤色、背景颜色、产品绿色银色包装颜色。不要让画面变暗，不要让每个片段逐渐降低亮度，不要改变色温，不要让产品颜色漂移。

如果生成声音，请严格按照口播内容自然说话；但音频只允许驱动口型，不能驱动产品演示、拆包或放下产品。最终声音可能由外部 TTS 替换，所以画面连续性、人物一致性、产品完整性和自然口型优先。音频中不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。

【在这里放入本段 SRT 或口播文本】
```

### 3.3 中文约束增强：产品完整性

Wan2.7-i2v 在图片+音频路径中出现过“包装稍微打开”，所以产品约束要更硬。

```text
产品完整性最高优先级：
- 产品盒从第一帧到最后一帧必须一直完整闭合。
- 不允许盒盖打开、包装翘起、边缘裂开、标签分离、内包装露出。
- 不允许出现条包、小袋、第二个盒子、额外标签或替代产品。
- 不允许因为口播、音频、嘴型或手势而触发产品展示动作。
- 主播只能稳定拿着产品，不能演示打开、使用、倒出、吃喝或对着产品低头查看。
```

### 3.4 中文约束增强：曝光与色彩

Round3 中 Wan2.7 链式片段出现逐段变暗。

```text
曝光和色彩锁定：
- 锁定输入图片的曝光、白平衡、对比度和色温。
- 主播肤色、背景墙面、厨房/客厅家具颜色、产品绿色银色包装颜色必须保持一致。
- 不要让后一段比前一段更暗。
- 不要自动降低亮度、增加阴影、改变色温或让画面偏灰。
- 如果这是链式生成，当前段第一帧的亮度必须与输入尾帧完全一致，并保持到最后一帧。
```

## 四、English Prompt Writing Guide

### 4.1 Universal Prompt Structure

Use eight blocks for Wan2.7-i2v prompts:

1. Task definition: realistic vertical 9:16 locked-camera livestream talking-head video.
2. Image role: input image is the first frame and visual source, not a style reference.
3. Host lock: same identity, clothing, microphone, background, seated posture.
4. Product lock: exact same closed product box, front-facing, always held.
5. Camera lock: no camera movement, no cuts, no close-up inserts.
6. Exposure lock: no progressive darkening, no white-balance or color drift.
7. Audio rule: audio may drive mouth movement only, not product demonstration. No background music, soundtrack, ambient music, or sound effects; audio may contain speech/voice only.
8. Negative constraints: no subtitles, no watermark, no new product, no opening package.

## 五、模型级操作建议

### 5.1 推荐输入

| 场景 | 推荐输入 | 说明 |
| --- | --- | --- |
| 默认生产 | 单图 `1.png` | 最稳，避免首尾帧带来的不可控过渡 |
| 链式长视频 | 上一段尾帧作为下一段首帧 | Round3 证明衔接自然，但要锁曝光 |
| 需要结尾姿态 | 首帧 + 尾帧 | 可测，但不要假设尾帧强生效 |
| 声画一体测试 | 图片 + 裁剪 WAV | 语音准确强，但必须防止音频诱导拆包 |

### 5.2 推荐时长

| 时长 | 建议 |
| --- | --- |
| 3 秒 | 适合最短链式测试；可拼接，但注意色彩逐段变暗 |
| 6 到 8 秒 | 更适合生产片段，减少拼接次数 |
| 90 秒长视频 | 拆成 8 秒左右片段，最终统一 TTS 和音轨 |

### 5.3 必查项

每段生成后必须检查：

- 是否 9:16。
- 产品是否完整闭合。
- 产品是否始终在手中。
- 是否生成额外包装、条包、小袋。
- 是否逐段变暗。
- 人物是否自然，AI 感是否可接受。
- 口型是否自然。
- 如果使用模型原生音频，拼接后是否音画同步。

### 5.4 硬淘汰规则

直接淘汰：

- 输出 16:9 或非竖屏。
- 产品打开、拆开、露出内包装。

## 七、最终推荐工作流

1. 先用单图 `1.png` 跑一个 6 到 8 秒片段，验证产品文字、人物自然度和是否有 AI 感。
2. 如果单图稳定，再测试上一段尾帧作为下一段输入，验证链式衔接和是否逐段变暗。
3. 如果需要声音准确，可测试图片 + 裁剪 WAV，但必须检查包装是否被打开。
4. 长视频最终建议外部 TTS，统一替换音轨，避免拼接后音画不同步；最终音轨不能有背景音乐、配乐、环境音乐或音效，只能有人声口播。
5. 每段都检查产品完整性、9:16、曝光一致、无字幕、无额外包装。
6. R2V 不进入正式生产链路。
