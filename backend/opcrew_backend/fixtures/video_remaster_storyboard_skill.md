# Video Remaster Storyboard Workflow Reference

这份参考文件用于指导 Skill Builder 生成稳定、完整、可复用的工作流型 skill。

核心目标：

1. 基于参考视频完成完整拆解，而不是只做机械分段。
2. 先理解素材，再抽象故事公式，再产出结构化结果。
3. 让关键帧、对白、节奏、场景变化和镜头动作共同参与判断。
4. 输出结果必须能服务于复刻、复拍、分析和团队执行。

输入原则：

1. 输入分为业务输入和素材输入。
2. 业务输入至少包含：行业、人设、产品介绍、目标受众、内容目标。
3. 素材输入至少包含：参考视频文件路径。
4. 如果信息缺失，可以做稳健补足，但不能脱离业务目标。

工作流原则：

1. 先读取视频和业务输入，明确拆解目标。
2. 先分析视频画面、声音、对白、节奏和结构，再进入结构拆解。
3. 先抽象出故事公式，再输出分段和组件槽位。
4. 输出三种拆分方式，而不是只给单一路径。
5. 输出原视频的对白、镜头说明、结构作用和复刻要点。
6. 结果要让拍摄团队和业务方都能直接理解和使用。

视频理解要求：

1. 通过关键帧理解人物关系、场景变化、镜头组织和动作推进。
2. 通过对白和转写理解冲突、判断、节奏与信息递进。
3. 不能只按视觉切点分段，必须结合句子边界、故事动作、转场和结构作用。
4. 关键帧与对白必须写入工作目录，供后续分析与复查。

输出结构建议：

1. 任务定位与工作目标。
2. 输入要求与工作目录要求。
3. 视频理解与分析顺序。
4. 故事公式提炼要求。
5. 分段方案输出要求。
6. 对白与镜头说明输出要求。
7. Hook / Trust / CTA 等组件槽位映射要求。
8. 结果包与质量校验要求。

质量标准：

1. 结构结论必须能从关键帧和对白中复查。
2. 输出必须清楚说明每段的结构作用，而不是只描述发生了什么。
3. 输出必须能支持业务复盘和内容复刻。
4. 所有核心结果都必须落在工作目录文件中，而不是只留在聊天回答中。
