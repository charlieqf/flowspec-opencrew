## 2. 判定标准

### 2.1 分类定义

- **确认死文件**：不在生产入口可达图中，未被注册表、运行时装载、人工 runbook 或外部调用约定使用，并有“已替代/已退休/仅兼容旧链”等独立证据。测试、文档或源码扫描脚本若仍读取它，会被列为“隐藏依赖”。
- **确认死代码**：所在文件仍存活，但赋值结果没有读取者，或函数/分支在现有入口和动态调度下均不可达；仅有“函数名零引用”时仍按候选处理。
- **孤儿候选**：仓内未发现接入点，但不能排除尚未接入的新开发、人工 CLI、插件式入口或仓外调用。孤儿候选不是删除授权，必须先由 owner 确认用途。
- **休眠/预留代码**：当前默认流程不使用，但存在明确设计、测试、feature flag、注册计划、近期开发记录或外部接口承诺。应补状态、owner 与接入/退出期限，不因静态不可达直接删除。
- **已过时代码**：已被当前入口替代、明确标记为 legacy/reference、或仅为旧协议/旧产品面保留。
- **冗余逻辑**：多个位置维护相同或高度重复的实现；它们可能都在运行，因此不等同于死代码。

核心原则：**“全仓零引用”只表示没有发现仓内接入证据，不能单独证明代码应删除。** 删除判断还要同时检查注册表、动态字符串加载、CLI/runbook、外部 API 约定、测试/CI、提交历史、替代实现和负责人意图。对于尚未接入的代码，审核应明确选择“补接入计划”或“确认废弃并删除”，不能长期保持无 owner 的模糊状态。

### 2.2 置信度

| 等级 | 含义 |
| --- | --- |
| 高 | 入口不可达、全仓零引用，并有路由/注册表/产品退休标记相互印证 |
| 中 | 静态零引用，但可能存在外部 API 客户端、运行时字符串装载或人工脚本调用 |
| 低 | 主要由命名、历史目录或重复形态推断，必须先补运行日志或业务确认 |

置信度描述的是“分类判断有多少证据”，不等于删除风险。即使是高置信度孤儿，只要无法排除未接入开发或人工入口，也应先完成人工确认。

## 3. 分析方法与边界

本轮执行了以下检查：

1. 从 `frontend/src/main.tsx` 出发解析静态 import、字面量动态 import、CSS import 和本地资源引用，构建前端生产依赖图。
2. 从 `backend/opcrew_backend/app.py` 出发解析 Python import，复核 FastAPI `include_router` 注册情况。
3. 对全部已跟踪 Python 源码做 AST 符号扫描，寻找顶层定义后全仓零 `Name` / `Attribute` 读取的函数。复核发现该扫描会漏掉 import alias、模块属性 re-export 和动态加载，因此结果仅为候选生成器，不是删除证明。
4. 使用 Ruff 的 `F401/F811/F821/F841` 规则检查未使用赋值、重复定义和未定义名称。
5. 对 Python 顶层函数做过一次 AST 规范化比较；原始扫描脚本、过滤条件和候选 manifest 未保存，因此精确组数/行数不可复现，只保留为方向性容量指标。
6. 复核 `tool_registry.json`、前端退休路由、源码型合同测试、StoryBoardRegression 说明和 Analysis V1 Backup 说明。
7. 对已跟踪源码做 SHA-1 比较，识别整文件完全重复项。
8. 对零引用的工具/维护脚本复核 CLI 入口、runbook、提交历史与同功能替代链，区分“确认死亡”和“尚未接入/人工执行”。

边界说明：

- 本报告以仓库内部调用关系为主，无法证明是否存在仓库外的 HTTP 客户端。因此，**已经注册的后端路由不会仅因前端没有调用就判为死代码**。
- ToolLibrary 中部分脚本可能被人工按文件路径执行。已在注册表中的脚本不因普通 import 为零而判死。
- `backend/scripts` 中的一次性迁移、回填和 smoke CLI 也可能由人工直接执行；没有 import、测试或 CI 引用是风险信号，不是死文件定论。必须结合 runbook、最近执行记录、迁移窗口和 owner 审核。
- `frontend/e2e/artifacts`、`backend/tests/artifacts` 和验收图片属于证据资产，不属于本轮“代码死文件”结论。其保留周期应另做存储治理审核。
- 工作树原本存在未提交改动和未跟踪验收产物；本轮没有修改这些内容。复核时本报告及 `待清理代码分析报告_2026-07-25.md.before_macmini4_sync_20260725` 备份文件仍未被 Git 跟踪；提交新仓库前应只选择正式报告，避免误提交临时备份。
