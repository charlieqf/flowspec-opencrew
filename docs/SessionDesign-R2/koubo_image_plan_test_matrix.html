判定口径

Image Plan 只负责“原图 + Image Prompt -> 新图”。它不看音频，不生成 Raw，不生成 Final。与 Video Plan 最大差异是：只有原图时，Image Plan 是“提示词白 / 新图灰”；必须等 Image Prompt 存在后，新图才变白。

颜色口径：白=可执行/待执行，灰=条件不满足或被下游产物消费，绿=文件存在/完成，黄=正在运行且文件尚未存在，红=执行失败且文件尚未存在。真实 Working 文件存在时绿色优先。
