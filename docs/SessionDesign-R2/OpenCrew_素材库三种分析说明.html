OpenCrew 素材库 · 用户说明

对白分析、画面分析、综合分析
分别是做什么的？

素材库对每条上传的原始视频提供三种分析。它们回答三个不同的问题：说了什么、画面是什么、以及把两者归纳成的可用内容索引。本页解释每种分析的目的、怎么操作、能得到什么，以及背后的简单原理。

适用版本：M0–M4 对白优先、单中点画面首版（2026-07-22 文档整理）。本页所述“检索素材”仍以对白片段为召回门槛。待审核、尚未交付的 R1 将把每个画面片段升级为 12.5% / 37.5% / 62.5% / 87.5% 四张采样图，并在一次多图模型请求中生成语义后开放无声素材检索；R1 上线时本页必须同步改成已交付操作说明。

对白分析和画面分析相互独立、可并行；综合分析是它们的“上层”，必须等两者都完成后才能运行。三者结果都是指向原视频某段时间的“虚拟索引”，不会生成新的视频文件。

白

对白分析

听“说了什么”
目的

把视频里说出来的话变成一条条带时间的可检索文字。有了它，你才能按台词内容在素材库里搜到这条视频，也才能给故事板的某句口播找到合适的素材。

这是三种分析里最基础的一种：只有完成对白分析的素材，才能被“检索素材”召回。

操作方法
  1. 进入某条素材的详情页，点击顶部的 对白分析。
  2. 如果使用云端语音识别，会要求你勾选 “允许把音频发往云端识别” 的授权；也可以选择本地识别、不外发音频。未授权时会明确提示原因，不会偷偷上传。
  3. 等待运行完成，状态会从 运行中 变为 已完成。
预期效果

得到若干条对白片段，每条包含精确的起止时间和这段话的文字（例如某条长口播得到 123 段）。完成后：

  • 素材列表“内容结构”列的 对白 会显示片段数量；
  • 这条素材进入全局检索的召回范围，可在故事板 / Agent 里被“检索素材”找到；
  • 在视频剪辑页的“对白片段”轨道上，能看到每句话对应的时间块，点一下即可定位剪切。
简单原理

用语音识别（ASR）把音轨转成带时间戳的字幕句，再做校准，按句切成一个个时间片段发布到中心索引。它只理解声音里的话，不理解画面——所以纯音乐、无人说话的素材，对白分析会正常完成但没有对白片段。

画

画面分析

看“画面是什么”
目的

理解视频画面上发生了什么：把视频切成一个个镜头/场景，取代表画面，并用文字描述其中的人物、场景、动作、物体。它补上了对白听不到的那一半信息。

操作方法
  1. 在素材详情页点击 画面分析。它内部分两步：先做画面结构（切场景 + 取关键帧），再做视觉语义（描述关键帧）。
  2. 视觉语义如果用云端视觉模型，会要求勾选 “允许把画面截图发往云端” 的授权；也可改用本地视觉模型。每次只发送当前场景的那一张关键帧，不发整段视频。
  3. 状态会分别显示 结构 已完成 和 语义 已完成；两步都完成才算画面分析就绪。
预期效果

得到若干画面片段（例如 22 段），每段包含时间范围、一张代表画面，以及简体中文的视觉描述与标签。在剪辑页的“画面片段”轨道上，可以看到每个场景的中文摘要。

简单原理

先用场景切分找到镜头边界，并在每个场景中间抽一张关键帧；再把这张关键帧交给支持看图的模型，让它只描述画面里看得见的东西。

为什么“动作”有时是空的？ 当前首版每个场景只取一张静止关键帧，单帧无法证明一段连续动作，所以系统会如实留空。规划中的 R1 虽改为四张稀疏采样图，但仍不会把静帧状态差异猜成连续动作。
综

综合分析

归纳成“可用内容索引”
目的

把“说了什么”和“画面是什么”融合成一个更高层、可直接使用的内容索引：给每一段配上标题、摘要、关键词和推荐用途，方便你快速判断“这段能用在哪里”，也让检索排序和剪辑推荐更准。

操作方法
  1. 先确保 对白分析 与 画面分析（结构 + 语义） 都已完成——在此之前，综合分析按钮是禁用的，并会提示还缺哪一项。
  2. 点击 综合分析 运行。它不需要再次读取视频，很快完成。
  3. 完成后在“综合分析”标签下查看综合片段列表。
预期效果

得到一组综合片段（例如 9 段），每段有一个概括性标题（如“介绍AI拓客能力”）、摘要、关键词，以及人物 / 场景 / 动作 / 物体标签，并标注它由哪些对白句和哪些画面场景支撑（可追溯的证据引用）。这是三种索引里最“好用”的一层。

简单原理

综合分析不再读取视频或图片，只消费对白分析和画面分析已经发布的文字结果，用大模型按时间把两边对齐、归纳、起标题、定用途。关键约束：凡是视觉方面的结论都必须有画面分析的证据支撑——不能只凭对白去“脑补”画面里没有的人或物。

常见问题

三个一定要按顺序做吗？
对白和画面互不依赖，可以并行。综合分析是上层，必须等对白与画面都完成才能运行——所以它的按钮在前两者未完成时是灰的，并会提示缺哪一项。
为什么运行分析时要我勾选“授权”？
如果分析使用云端模型，会把音频（对白）或画面截图（视觉语义）发到云端处理。系统不会在你未明确同意前外发数据，因此需要你先勾选授权；你也可以选择本地模型、完全不外发。这是隐私与合规的保护，不是多余步骤。
只做了对白分析，能用检索找素材吗？
可以。完成对白分析即可被“检索素材”召回。画面分析和综合分析会让结果更准、更好用，但不是检索的必要条件。
为什么有的视觉/综合片段“动作”是空的？
当前首版每个场景只用一张静止关键帧。规划中的 R1 会改为每片段四张稀疏采样图，提高人物、物体和场景覆盖，但四张静帧仍无法证明完整连续动作；动作证据不足时系统继续如实留空。
分析会改变或替换我的原始视频吗？
不会。三种分析产出的都是指向原视频某段时间的虚拟索引，原始视频文件保持不变。只有你在剪辑页主动“剪切”后，才会生成新的片段文件。
素材列表里的“质量”列是什么意思？
它按真实统计展示分析片段的质量分布，例如可用（可直接使用）与待复核（置信度较低、建议人工确认）的数量；尚未分析的素材会显示“暂无质量数据”。
