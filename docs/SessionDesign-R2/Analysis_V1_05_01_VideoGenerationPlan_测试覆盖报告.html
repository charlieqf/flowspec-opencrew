生成计划字段查验点

字段 查验意义
segments[].dialogue_ids 确认每个视频片段覆盖哪些 dialogue，且每个 dialogue 只出现一次。
segments[].duration 原始时间轴长度，来自 dialogue 的 start / end。
segments[].planned_video_duration 给视频模型生成时使用的时长，至少等于 min-video-seconds。
segments[].first_frame.source_type 确认首帧来源：原图生成新图、新图片、上传素材落位、上一段尾帧。
segments[].dependencies 确认依赖上一段视频或上一 Scene 尾帧时，后续工具能按依赖顺序执行。
materialize_first_frame 确认从原素材 / 上传素材拖入的新图片，后续视频工具知道从哪里拷贝到 Working。
planned_outputs.video_path 确认视频落位使用该 segment 第一个 dialogue key。
status / blocked_reason / skipped_reason 确认 planned、skipped、blocked 三类状态不会被混淆。
