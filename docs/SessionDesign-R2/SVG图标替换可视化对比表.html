OpenCrew SVG 图标替换可视化对比表

左侧是当前 OpenClip / Koubo / Analysis_V1 中的手写图标，右侧是 `SessionDesign-R2/icons.tsx` 和 `ExecutionPlanModal.tsx` 里更推荐的 Gemini 图标。优先级按语义错误、视觉收益、替换风险综合排序。

P0 先换 P1 建议换 P2 可统一 KEEP 保留
第一批 KouboVideoPlanModal：Audio、Scene、Segment、Video、Sync，直接套用 ExecutionPlanModal 的业务映射。
第二批 DialogueCard / KouboSidebar：图片、视频、音频素材槽、切分操作，统一媒体语义。
第三批 Analysis_V1：TTS Builder、Prompt Builder、文档、上传、设置类工具按钮逐步统一。
暂不替换 播放态、保存、价格、模型配置里的专用模型图标，当前语义仍然更明确。
类别 当前图标 建议图标 优先级 建议替换位置 原因 替换动作
Audio 任务
PauseIcon当前：KouboVideoPlanModal
MicGemini：ExecutionPlanModal
P0 KouboVideoPlanModal.jsx 顶部任务统计、AUDIO badge Pause 是播放暂停状态，不是音频生成任务；Mic 更适合 TTS / 声音生成。 `PauseIcon` -> `Mic`
Sync / Lipsync
SpeedIcon当前：Sync Tasks
AudioLinesGemini：ExecutionPlanModal
P0 KouboVideoPlanModal.jsx 顶部 Sync、pipeline SYNC badge Speed 表示速度设置，容易误解；AudioLines 至少能表达“声音驱动同步”。 `SpeedIcon` -> `AudioLines`，后续补专用 LipsyncIcon
Segment 统计
SpeedIcon当前：Segments
LayoutListGemini：ExecutionPlanModal
P0 KouboVideoPlanModal.jsx 顶部 Segment 指标 Segment 是计划切片/列表，不是速度；LayoutList 的语义和视觉都更准。 `SpeedIcon` -> `LayoutList`
Scene 统计
WorkflowIcon当前：Scenes
LayersGemini：ExecutionPlanModal
P0 KouboVideoPlanModal.jsx 顶部 Scene 指标 主标题已经用 Workflow，Scene Count 用 Layers 更像场景层级，也减少重复。 `WorkflowIcon` -> `Layers`
Video 任务
FilmIcon当前：Video Tasks
ClapperboardGemini：ExecutionPlanModal
P1 KouboVideoPlanModal.jsx Video Tasks、pipeline VIDEO badge Film 更适合 Shot / 素材片段；Clapperboard 更适合生成视频任务。 `FilmIcon` -> `Clapperboard`
Shot / 视频片段
FilmIcon当前：Shot / brand
FilmGemini：icons.tsx
P1 KouboSidebar.jsx、Shot 指标、视频素材槽 Gemini 版本胶片孔更完整，小尺寸下也更像“片段/镜头”。 `FilmIcon` -> `Film`
Image / 首帧图
ImageIcon当前：Koubo
ImageIconGemini：ExecutionPlanModal
P1 DialogueCard.jsx、KouboSidebar.jsx、Frame Tasks Gemini 图片图标构图更饱满，适合原图、新图、首帧图统一使用。 替换为 Gemini `ImageIcon`
音频素材槽
VolumeIcon当前：Audio slot
AudioLinesGemini：icons.tsx
P1 DialogueCard.jsx 音频素材槽、KouboSidebar.jsx 绑定状态 Volume 更像输出音量；AudioLines 更像素材/波形。播放按钮里仍可保留 Volume/Play/Pause。 素材槽 `VolumeIcon` -> `AudioLines`
切分操作
ScissorIcon当前：split scene / shot
ScissorsGemini：icons.tsx
P1 DialogueCard.jsx Split Scene / Split Shot Gemini scissors 更完整，剪辑语义更明显。 `ScissorIcon` -> `Scissors`
刷新 / 重跑
RefreshIcon当前：timing / reload
RefreshCwGemini：icons.tsx
P1 KouboTimingMenu.jsx、reload / regenerate 入口 Gemini 版本视觉更平衡，和同套图标的箭头风格一致。 `RefreshIcon` -> `RefreshCw`
上传
UploadIcon当前：TTS Builder
UploadCloudGemini：icons.tsx
P1 AnalysisV1TTSBuilder.jsx 上传参考声音 UploadCloud 更像素材/服务上传；如果是本地导入，也可以用 ArrowUpToLine。 `UploadIcon` -> `UploadCloud`
参数 / 设置
SlidersIcon当前：Prompt / timing
Settings2Gemini：icons.tsx
P1 Prompt Builder、Builder-G Timing、参数面板入口 Settings2 更紧凑，适合作为工具按钮；真实滑杆界面可保留 Sliders。 入口按钮换 `Settings2`
文档 / 提示词
DocumentIcon当前：Prompt preview
FileTextGemini：icons.tsx
P1 查看最终提示词、计划详情、文档入口 FileText 文档折角和文本线更完整，和 Code 图标搭配更统一。 `DocumentIcon` -> `FileText`
智能生成
SparkIcon当前：Storyboard
SparklesGemini：icons.tsx
P1 自动生成、AI 建议、重写建议 Sparkles 更丰富，更像 AI 生成动作；普通保存/刷新不要滥用。 `SparkIcon` -> `Sparkles`
播放状态
PlayIcon当前：播放控件
PlayGemini：icons.tsx
KEEP 音频播放、视频播放、timeline 播放 播放态用实心图标更醒目，Gemini 描边版更适合“执行计划”入口。 播放器保留；执行按钮可换
保存
SaveIcon当前：保存
暂缺 SaveGemini：无同语义图标
KEEP Header 保存、TTS 保存、版本保存 Gemini 当前没有 SaveIcon；用 Check 代替会把“保存动作”和“已完成状态”混在一起。 保留当前 SaveIcon，后续补 Gemini 风格 Save

  • Shot=Film、Scene=Layers、Segment=LayoutList、Audio=Mic、Image=ImageIcon、Video=Clapperboard、Sync=AudioLines。
  • 当前最刺眼的问题是 Audio Tasks 用暂停图标、Segment/Sync 用速度表图标，建议优先处理。
  • 本轮已扩展到整个 OpenCrew 前端系统：主壳导航、Debug Console、WorkflowAssistant、OpenClip、OCRebuild、OCStoryBoard、Analysis_V1、ModelConfig 中的 P0/P1 通用图标都纳入替换。
  • 真正缺口是 LipsyncIcon、SaveIcon、VoiceTimingIcon，这几个最好后续按 Gemini 风格补齐。
