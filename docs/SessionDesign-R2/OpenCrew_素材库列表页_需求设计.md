# OpenCrew 素材库列表页需求设计

版本：v0.1

状态：历史归档（最早列表阶段）。本文保留实体建模和页面演进背景，不再作为当前完整产品合同；现行范围以[素材库需求评审 v0.9.3](./OpenCrew_素材库综合分析_视频剪辑与跨页面语义检索_需求评审.md)和[开发实施设计 v1.1.4](./OpenCrew_素材库综合能力_开发实施设计_v1.md)为准。

归档说明：本文所述“不包含上传、分析和剪辑”只代表当时的第一阶段边界，这些能力已经在 M0–M4 中实现。

## 1. 背景

当前 OpenCrew 左侧已经有「任务列表（口播）」「视频分析（口播）」「故事版（口播）」等业务入口，但缺少一个面向原始视频素材的统一入口。

后续素材库主要承载用户拍摄或收集的视频，并围绕这些视频形成一套类似 Analysis 工具集的分析能力，包括：

1. 按 SRT / 对白时间轴拆分视频。
2. 按画面变化和叙事语义拆分画面逻辑单元。
3. 根据对白内容快速搜索并挑选可用片段。
4. 标记适合剪辑使用的候选片段。
5. 识别口误、磕巴、重复、异常停顿等可能需要删减的小片段。

第一阶段先建立「素材从哪里进入、在哪里被找到、当前处于什么状态」的产品入口，因此只建设素材库列表页。上传、拆分、分析、剪辑均作为后续独立需求展开。

## 2. 页面定位

### 2.1 素材库列表的主实体是视频素材

素材库列表的每一行代表一条独立的视频素材，而不是一个 Task、Session、分析 Run 或剪辑工程。

推荐的实体关系：

```text
一条视频素材
  -> 可以有一份基础媒体信息
  -> 可以有多次分析记录
  -> 可以产生 SRT 对白单元
  -> 可以产生画面逻辑单元
  -> 可以产生剪辑问题标记
  -> 可以被一个或多个 Task / 剪辑工程引用
```

列表中可以展示分析结果摘要，但不能因为重新分析而复制出多条素材记录。

### 2.2 素材库不是任务列表

两者管理对象不同：

| 页面 | 管理对象 | 用户主要问题 |
| --- | --- | --- |
| 素材库 | 原始视频及其可复用内容 | 我有哪些视频？里面有什么？哪些片段可用？ |
| 任务列表（口播） | 创作或生产任务 | 某个视频任务进行到哪一步？产出了什么？ |

素材可以先于 Task 存在，也可以被多个 Task 复用。不得为了展示素材而强制为每条素材创建口播 Task。

### 2.3 与现有 Asset Library 的边界

项目当前已经存在以下任务内路由：

```text
#/koubo-asset-library/tasks/{taskId}
```

该页面是某个 StoryBoard Task 内部的图片、视频、音频素材及 Agent 工作台，依赖明确的 `taskId`，属于任务内素材池。

本需求新增的是全局一级「素材库列表」，用于管理可跨 Task 复用的原始视频。两者必须在产品语义和路由上区分：

| 能力 | 新增素材库列表 | 现有任务内 Asset Library |
| --- | --- | --- |
| 是否需要先选 Task | 否 | 是 |
| 主实体 | 原始视频素材 | 当前 Task 的图片、视频、音频资产 |
| 是否跨 Task 复用 | 是 | 默认服务当前 Task |
| 页面形态 | 全局列表 | 单 Task 工作台 |
| 本期是否调整 | 新增列表需求 | 不修改 |

## 3. 本期目标

本期页面需要让用户完成以下事情：

1. 从左侧导航进入独立的「素材库」。
2. 浏览系统中已有的视频素材。
3. 通过名称、对白摘要、标签等信息快速搜索素材。
4. 按素材状态、分析状态、时间和标签筛选素材。
5. 直接看到素材时长、规格、对白、逻辑单元和剪辑提示等摘要。
6. 预览素材并查看基础信息。
7. 完成重命名、标签维护、归档和删除等基础列表管理。
8. 在没有素材、加载中、加载失败和无搜索结果时得到明确反馈。

## 4. 本期范围

### 4.1 本期包含

1. 左侧一级导航入口。
2. 素材库列表路由和列表页面。
3. 页面标题和素材数量摘要。
4. 关键词搜索。
5. 状态、标签、时长和更新时间筛选。
6. 表格展示、排序和分页。
7. 单条视频快速预览。
8. 基础元数据查看。
9. 重命名、编辑标签、归档、恢复和删除。
10. 空态、加载态、错误态和无结果状态。
11. 对后续分析结果字段的只读摘要展示。
12. 点击素材名称进入该素材的只读详情页。

### 4.2 本期明确不包含

1. 上传文件、拖拽上传、批量导入和文件选择器。
2. 视频转码、代理文件生成和缩略图生成逻辑。
3. SRT 生成、识别、校对和重新拆分。
4. 按图片或画面变化进行逻辑单元拆分。
5. 内容理解、人物识别、场景识别和语义标签生成。
6. 口误、磕巴、重复、停顿等问题的检测工具。
7. 自动挑片、智能推荐、相似片段搜索和向量检索。
8. 时间线、入点出点、裁剪、拼接、字幕编辑和成片导出。
9. Analysis 工具集的选择、配置、运行、重试和日志展示。
10. 与任务列表、故事版或剪辑工程的素材绑定流程。
11. 对现有任务内 `#/koubo-asset-library/tasks/{taskId}` 页面的重构。

本期页面可以展示后端已经提供的分析摘要；如果没有数据，必须显示「未分析」或 `-`，不得由前端猜测或伪造分析结果。

## 5. 导航与路由

### 5.1 导航位置

按照当前页面结构，在「任务列表（口播）」上方新增一级入口：

```text
Connection
素材库
任务列表（口播）
视频分析（口播）
故事版（口播）
计费
```

导航名称首版使用：

```text
素材库
```

图标建议使用视频素材库或文件夹类图标，不能继续使用任务列表的普通文件图标，也不要使用 Analysis 的波形图标。

### 5.2 路由

推荐新路由：

```text
#/media-library
```

原因：该素材库是全局原始视频库，不绑定 `koubo` Task，也不应与现有任务内 `#/koubo-asset-library/tasks/{taskId}` 混淆。

兼容实现如果必须保留业务前缀，可以使用：

```text
#/koubo-media-library
```

但不得直接使用不带 Task ID 的 `#/koubo-asset-library` 作为新列表路由。

### 5.3 导航状态

1. 进入素材库列表后，仅「素材库」导航高亮。
2. 进入任务内 Asset Library 时，仍按现有逻辑归属于「故事版（口播）」，不得高亮新的全局素材库。
3. 刷新素材库 URL 后，页面和导航状态必须正确恢复。
4. 浏览器前进、后退时，搜索和筛选参数应从 URL 恢复。

推荐将列表条件保存在查询参数中：

```text
#/media-library?q=老板&analysis=ready&tag=采访&sort=updated_desc&page=1
```

## 6. 页面信息架构

页面整体视觉和密度参照现有「任务列表（口播）」，保持同一套 Shell、边距、表格、按钮、筛选器和状态标签风格。

从上到下分为四个区域：

1. 页面标题区。
2. 搜索与筛选区。
3. 素材列表区。
4. 分页区。

### 6.1 页面标题区

左侧显示：

```text
素材库
```

标题旁显示当前结果总数，例如：

```text
共 128 条视频
```

本期不提供「上传视频」「新建分析」「运行工具」等按钮。标题右侧保留标准操作区的布局空间即可，但不能展示不可用的假按钮。

### 6.2 搜索与筛选区

第一行使用与任务列表一致的横向布局。

搜索框占主要宽度，placeholder：

```text
搜索素材名称、对白、标签、文件名...
```

首版筛选项：

| 筛选项 | 选项 |
| --- | --- |
| 分析状态 | 全部、未分析、处理中、部分完成、已完成、失败 |
| 时长 | 全部、1 分钟内、1～5 分钟、5～30 分钟、30 分钟以上 |
| 标签 | 全部标签、具体标签；支持多选时放入二级筛选面板 |
| 更新时间 | 全部、今天、近 7 天、近 30 天、自定义 |
| 归档 | 默认不显示；通过「显示归档」复选框切换 |

默认排序：

```text
更新时间从新到旧
```

可选排序：

1. 更新时间从新到旧。
2. 更新时间从旧到新。
3. 时长从长到短。
4. 时长从短到长。
5. 素材名称 A-Z / Z-A。

筛选逻辑要求：

1. 多个不同筛选项之间使用 AND。
2. 同一多选筛选项内部使用 OR。
3. 修改搜索或筛选条件后回到第 1 页。
4. 提供「清除筛选」动作。
5. 搜索输入建议 300ms 防抖，不应每输入一个字符就并发多次请求。

### 6.3 素材列表区

首版采用表格视图，不同时建设卡片视图。表格与现有任务列表保持一致的圆角容器、表头底色、行高和状态标签。

推荐字段：

| 字段 | 展示内容 | 说明 |
| --- | --- | --- |
| 操作 | 预览、更多 | 常用操作前置，危险操作放入更多菜单 |
| 素材 | 缩略图、素材名称、原始文件名 | 名称最多两行，文件名次级显示 |
| 媒体信息 | 时长、分辨率、格式、文件大小 | 缺失字段显示 `-` |
| 对白摘要 | 语言、对白单元数、首句或内容摘要 | 可被关键词命中并高亮 |
| 分析状态 | 未分析、处理中、部分完成、已完成、失败 | 只读展示，不在列表运行工具 |
| 内容结构 | SRT 单元数、画面逻辑单元数、候选片段数 | 无结果显示 `-`，不能显示 0 造成误解 |
| 剪辑提示 | 口误、磕巴、重复、长停顿等问题总数 | 仅展示摘要数量，不在本期展开问题详情 |
| 标签 | 最多展示 3 个，超出显示 `+N` | 支持在基础管理中编辑 |
| 更新时间 | 最近一次元数据或分析结果更新时间 | 使用系统统一日期格式 |

推荐在 1616px 左右宽度下完整展示主要字段；窄屏时优先保留「素材、时长、分析状态、内容结构、剪辑提示、更新时间」，其余信息可折叠到行内详情或更多菜单，禁止横向字段互相覆盖。

### 6.4 行内展示规则

#### 素材名称

1. 用户展示名优先于原始文件名。
2. 没有展示名时回退到原始文件名。
3. 完整名称通过 `title` 或可访问 Tooltip 查看。
4. 搜索命中的名称或对白关键词可以高亮，但不能改变原文。
5. 素材名称是详情页入口，点击后进入 `#/media-library/{asset_id}`。

#### 缩略图

1. 根据视频实际宽高比选择缩略图容器：横屏以 16:9 展示，竖屏以 9:16 展示。
2. 横屏与竖屏都使用完整画面居中展示，不强制裁掉主体。
3. 缩略图不可用时展示视频占位图标。
4. 缩略图上显示总时长。

#### 分析状态

统一状态建议：

| 状态值 | 页面文案 | 颜色语义 |
| --- | --- | --- |
| `not_analyzed` | 未分析 | 中性灰 |
| `processing` | 处理中 | 蓝色 |
| `partial` | 部分完成 | 橙色 |
| `ready` | 已完成 | 绿色 |
| `failed` | 失败 | 红色 |

「部分完成」表示某些摘要已经存在，例如有 SRT 但没有画面逻辑单元。列表只负责展示，不在本期定义如何补跑。

#### 内容结构

建议采用紧凑数字标签：

```text
对白 42  |  画面 18  |  候选 9
```

这里的「候选」仅表示已有分析结果中被标记为可用的片段数量。本期不定义候选片段的生成规则。

#### 剪辑提示

当存在结果时，优先展示总数和最高频问题：

```text
问题 6 · 磕巴 3
```

当分析已完成且确认没有问题时显示：

```text
未发现明显问题
```

当未执行相关分析时显示：

```text
-
```

不得把「尚未分析」显示成「0 个问题」。

## 7. 列表交互

### 7.1 选择一行

1. 点击非按钮区域选中当前素材行。
2. 选中态使用与任务列表一致的浅色高亮。
3. 再次点击已选中行可以取消选择。
4. 选中本身不触发工具、不创建 Task，也不修改素材。

### 7.2 快速预览

点击「预览」后，在当前页面打开视频预览层或右侧预览抽屉，至少展示：

1. 视频播放器。
2. 素材名称。
3. 时长、分辨率、格式、大小。
4. 原始文件名。
5. 标签。
6. 添加时间和更新时间。
7. 已有分析摘要的只读展示。

预览能力只是播放与查看，不包含打点、裁剪、片段选择、字幕编辑和问题修正。

### 7.3 打开素材详情

1. 点击素材名称进入独立详情页，不打开快速预览抽屉。
2. 详情页保持左侧「素材库」导航高亮。
3. 详情页首版展示原片预览、基础媒体信息、OpenCut 内容结构、片段质量、对白摘要和标签。
4. 详情页首版不提供上传、工具运行、剪辑或片段修改操作。

### 7.4 更多菜单

首版更多菜单包含：

1. 重命名。
2. 编辑标签。
3. 归档。
4. 恢复归档。
5. 删除。

本期不出现以下动作：

1. 开始分析。
2. 重新分析。
3. 按 SRT 拆分。
4. 按画面拆分。
5. 智能挑片。
6. 开始剪辑。
7. 添加到任务。

### 7.5 重命名与标签

1. 重命名只修改用户展示名，不修改原始文件名和磁盘文件名。
2. 展示名去除首尾空格后不能为空。
3. 标签支持新增已有标签或输入新标签。
4. 同一素材不能保存重复标签。
5. 保存成功后局部更新当前行，不整页闪烁。

### 7.5 归档与删除

1. 归档后默认从列表消失，可通过「显示归档」找回。
2. 归档必须可恢复。
3. 删除是危险操作，必须二次确认。
4. 删除确认框必须显示素材名称。
5. 如果素材已被 Task 或其他工程引用，页面必须阻止直接删除，或明确告知影响并采用后端规定的安全策略；不能只在前端静默移除列表行。
6. 本期不定义磁盘文件、代理文件和分析产物的级联删除规则，必须由后续存储需求单独确认。

## 8. 页面状态

### 8.1 首次空态

当素材库中没有任何素材时显示：

```text
素材库还是空的
以后加入的视频会统一显示在这里，方便检索、分析和挑选片段。
```

本期不展示上传按钮。上传能力接入后再在空态中增加主操作。

### 8.2 无搜索结果

```text
没有找到符合条件的素材
请尝试修改关键词或清除筛选条件。
```

提供「清除筛选」按钮。

### 8.3 加载状态

1. 首次加载使用表格骨架屏。
2. 已有数据刷新时保留旧列表，显示轻量刷新状态。
3. 翻页和排序时避免整个 Shell 白屏。

### 8.4 错误状态

1. 首次加载失败时显示错误说明和「重新加载」。
2. 有旧数据时刷新失败，保留旧数据并显示非阻断 Banner。
3. 单条操作失败，只回滚并提示对应行，不清空整页。

### 8.5 处理中状态

如果后端返回素材处于分析处理中：

1. 列表显示「处理中」及最近更新时间。
2. 可以按照合理轮询或事件机制刷新状态。
3. 本期不展示步骤进度条，不提供停止、重试或查看日志。
4. 用户离开列表后不得因为前端轮询中断后端任务。

## 9. 素材列表数据模型

以下是列表页所需的最小读模型，不代表上传或分析工具的内部存储结构：

```json
{
  "asset_id": "media_000128",
  "display_name": "老板采访第二机位",
  "original_filename": "A002_C003_0712.mp4",
  "media_type": "video",
  "thumbnail_url": "/api/media-library/media_000128/thumbnail",
  "preview_url": "/api/media-library/media_000128/preview",
  "duration_ms": 386420,
  "width": 3840,
  "height": 2160,
  "format": "mp4",
  "size_bytes": 1280043021,
  "language": "zh-CN",
  "dialogue_summary": "我们今年最重要的产品方向是……",
  "analysis_status": "ready",
  "analysis_summary": {
    "srt_unit_count": 42,
    "visual_unit_count": 18,
    "candidate_clip_count": 9,
    "editing_issue_count": 6,
    "top_editing_issue": "stutter",
    "top_editing_issue_count": 3
  },
  "tags": ["采访", "老板", "产品介绍"],
  "archived": false,
  "referenced_by_count": 2,
  "created_at": "2026-07-12T14:06:00+08:00",
  "updated_at": "2026-07-14T09:30:00+08:00"
}
```

字段规则：

1. `asset_id` 是素材稳定主键，不能使用文件路径代替。
2. `media_type` 首版固定为 `video`，但保留字段便于未来扩展。
3. 时间统一由后端返回带时区的 ISO 8601。
4. `duration_ms` 使用整数毫秒，前端只负责格式化。
5. `analysis_summary` 可以为空；为空表示没有摘要，不代表数量为零。
6. 任何数量字段都必须是非负整数或 `null`。
7. `dialogue_summary` 是检索与列表摘要，不等同于完整 SRT。
8. `referenced_by_count` 用于删除保护，不要求列表默认展示。

## 10. 列表接口边界

本期只需要列表和基础管理接口，不设计上传、分析或剪辑接口。

### 10.1 列表

```text
GET /api/media-library
```

建议参数：

```text
q
analysis_status
duration_range
tags
updated_from
updated_to
include_archived
sort
page
page_size
```

返回：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "page_size": 20
}
```

### 10.2 单条基础信息

```text
GET /api/media-library/{asset_id}
```

只返回预览和基础摘要所需数据，不要求返回完整 SRT、完整画面单元或分析日志。

### 10.3 修改基础信息

```text
PATCH /api/media-library/{asset_id}
```

本期只允许修改：

```json
{
  "display_name": "新的展示名",
  "tags": ["采访", "产品"]
}
```

### 10.4 归档与恢复

```text
POST /api/media-library/{asset_id}/archive
POST /api/media-library/{asset_id}/restore
```

### 10.5 删除

```text
DELETE /api/media-library/{asset_id}
```

若存在引用或后端不允许删除，应返回可展示的业务错误码和原因，不能只返回泛化 500。

## 11. 权限与安全

首版至少区分：

| 能力 | 查看者 | 编辑者 / 管理员 |
| --- | --- | --- |
| 查看列表和预览 | 允许 | 允许 |
| 搜索、筛选、排序 | 允许 | 允许 |
| 重命名和编辑标签 | 不允许 | 允许 |
| 归档和恢复 | 不允许 | 允许 |
| 删除 | 不允许 | 按权限允许 |

安全要求：

1. 后端必须再次校验权限，不能只隐藏前端按钮。
2. 预览地址不得允许通过任意本地路径读取文件。
3. 列表接口不得返回服务器绝对路径、内部凭据和模型配置。
4. 删除、归档和恢复需要记录操作人和时间。

## 12. 可访问性与易用性

1. 所有图标按钮必须有 `title` 和 `aria-label`。
2. 状态不能只依赖颜色，需要同时显示文字。
3. 表格行、预览按钮和更多菜单支持键盘操作。
4. 弹窗打开后焦点进入弹窗，关闭后回到触发按钮。
5. 视频预览提供播放、暂停、音量和进度控制。
6. 文件大小、时长和日期采用用户可读格式。
7. Tooltip 不得遮挡主要操作。

## 13. 性能要求

1. 默认分页大小为 20，可选 20 / 50 / 100。
2. 列表接口不得返回完整字幕、完整画面单元或完整问题明细。
3. 缩略图懒加载，首屏以外不立即下载。
4. 视频文件不得在列表加载时自动下载或自动播放。
5. 搜索、防抖、排序和筛选请求需要取消或忽略过期响应，避免旧结果覆盖新结果。
6. 1000 条以上素材时仍通过服务端筛选、排序和分页，不把全量数据一次性拉到浏览器。

## 14. 视觉文案基线

页面名称及核心文案统一如下：

| 场景 | 文案 |
| --- | --- |
| 左侧导航 | 素材库 |
| 页面标题 | 素材库 |
| 搜索框 | 搜索素材名称、对白、标签、文件名... |

首版不使用「素材任务」「分析任务」「视频项目」作为列表行名称，避免再次把素材与 Task 混为一体。

## 16. 验收标准

### 16.1 导航验收

1. 「素材库」位于「任务列表（口播）」上方。
2. 点击后进入独立的素材库列表路由。
3. 刷新、前进、后退后导航高亮正确。
4. 新素材库不会覆盖或改变现有任务内 Asset Library 路由。

### 16.2 列表验收

1. 一条视频只展示为一条素材记录。
2. 列表能展示缩略图、名称、时长、规格、对白摘要、分析状态、内容结构、剪辑提示、标签和更新时间。
3. 缺少分析结果时显示「未分析」或 `-`，不把缺失数据显示为 0。
4. 搜索可以命中素材名称、原始文件名、对白摘要和标签。
5. 多条件筛选、排序和分页结果正确。
6. 搜索和筛选状态能通过 URL 恢复。
7. 预览不会触发任何分析或素材修改。
8. 横屏素材以 16:9 缩略图展示，竖屏素材以 9:16 缩略图展示，均不强制裁剪。
9. 点击素材名称可进入对应素材详情页。

### 16.3 管理验收

1. 重命名不修改原始文件名。
2. 标签保存后当前行立即更新。
3. 归档素材默认从列表消失，通过「显示归档」可以找到并恢复。
4. 删除必须二次确认。
5. 被引用素材不能被静默删除。
6. 无编辑权限的用户看不到或无法使用修改类操作。

### 16.4 状态验收

1. 首次空态、无搜索结果、加载中、加载失败均有独立状态。
2. 刷新失败时不会清空已经展示的旧数据。
3. 单条操作失败只影响对应素材。
4. `not_analyzed / processing / partial / ready / failed` 均有明确文字和视觉区分。

### 16.5 范围验收

本期页面不得出现或实现：

1. 上传视频。
2. 运行 SRT 分析。
3. 运行画面逻辑单元分析。
4. 运行口误或磕巴检测。
5. 智能挑片。
6. 时间线剪辑。
7. 添加到 Task 或 StoryBoard。

## 17. 后续需求拆分建议

列表页确认后，后续能力建议按以下顺序分别立项，避免把所有能力堆进一个页面：

1. 素材上传与入库需求。
2. 素材详情与原片预览需求。
3. SRT / 对白拆分与校对需求。
4. 画面逻辑单元拆分需求。
5. 对白搜索与候选片段挑选需求。
6. 口误、磕巴、重复和停顿检测需求。
7. 片段入点 / 出点与轻量剪辑需求。
8. 素材绑定 Task、StoryBoard 和剪辑工程需求。

各后续能力必须复用本需求中的 `asset_id`，不得各自再建立互不关联的视频主实体。
