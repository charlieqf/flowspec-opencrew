# OpenCrew 素材库详情页需求与独立模块设计

版本：v1.0
状态：历史归档（占位视图阶段）。本文记录真实工具接入前的页面原型，不再作为当前详情页、分析运行或剪辑合同；现行范围以[需求评审 v0.9.3](./OpenCrew_素材库综合分析_视频剪辑与跨页面语义检索_需求评审.md)和[开发实施设计 v1.1.4](./OpenCrew_素材库综合能力_开发实施设计_v1.md)为准。
工具集名称：OpenCut V1

归档说明：本文“只实现页面视图”“不执行真实轮询/重新运行”等限制已经被 M0–M4 的真实分析链路取代。

## 1. 页面目标

素材详情页不是传统的媒体元数据详情卡，而是单条视频素材的 OpenCut V1 分析工作台。

页面需要让用户在同一个素材、Task 和 Session 下：

1. 查看素材名称、OpenCut 状态、Task 和 Session 身份。
2. 分别配置并运行对白分析、画面分析和综合分析工具集。
3. 通过 Tab 查看三套相互独立的产出物和分析结果。
4. 在左侧查看只读片段列表，在右侧同步查看源视频片段、Keyframe 和视觉描述。
5. 查看素材基础信息，但不让基础信息挤占主要分析工作区。

首版只实现页面视图和状态表达，不接入 OpenCut V1 工具的真实执行、进度轮询和结果文件读取。

## 2. 已确认产品决定

1. 一个素材对应一个 OpenCut Task 和一个 OpenCrew Session。
2. 对白分析、画面分析和综合分析在同一 Task、同一 Session 下运行，但分别产生独立 Attempt、产出物和结果。
3. 三套结果互不覆盖，通过详情页 Tab 独立呈现。
4. 三个分析按钮点击后打开对应工具集配置抽屉，不直接启动运行。
5. 左侧通过 Tab 切换对白、画面和综合分析结果。
6. 右侧同时展示视频片段、全部相关 Keyframe 和视觉描述。
7. 首版所有分析结果只读，不提供 SRT、边界、Keyframe 或分析描述编辑。
8. 素材格式、尺寸、大小和源文件路径收进顶部折叠信息区。
9. 首版不提供「全部分析」按钮。
10. 综合分析必须等待对白分析和画面分析全部完成；未满足依赖时按钮禁用并说明原因。

## 3. 实体关系

```text
MediaAsset（素材库一行）
  -> OpenCutTask（唯一）
  -> OpenCrew Session（唯一）
      -> Dialogue Analysis Attempts
      -> Visual Analysis Attempts
      -> Composite Analysis Attempts
```

约束：

1. 重新运行某套分析只新增 Attempt，不创建新素材、不创建新 Task、不创建新 Session。
2. 三套分析可以有不同状态、不同完成时间和不同输出目录。
3. 综合分析依赖对白与画面分析的可用产出物。
4. 上传流程创建素材和 Session 时同步创建 OpenCut Task。
5. 历史素材如果已有 Session 但没有 OpenCut Task，数据库迁移负责补建 Task。

## 4. 页面路由与导航

页面路由保持：

```text
#/media-library/{asset_id}
```

导航要求：

1. 左侧一级导航继续高亮「素材库」。
2. 页面提供「返回素材库」按钮。
3. 刷新详情 URL 后可以恢复当前素材。
4. 首版不把当前 Tab 写入 URL；后续如果需要分享精确结果视图，可以增加 `?tab=dialogue|visual|composite`。

## 5. 页面信息架构

页面从上到下划分为：

1. 返回入口。
2. OpenCut 工作台头部。
3. 可折叠素材信息。
4. 分析结果 Tab。
5. 左侧片段列表和右侧视觉预览工作区。
6. 工具集配置抽屉。

## 6. OpenCut 工作台头部

### 6.1 标题与身份

头部左侧必须在同一行显示：

1. 步骤标识。
2. 页面标题 `OpenCut`，不显示素材文件名称，也不显示 `V1`。
3. Task 总状态，例如 `DRAFT`、`RUNNING`、`PARTIAL`、`COMPLETED`、`FAILED`。
4. `任务 #ID / 会话 #ID`。

素材名称和原始文件名都不在工作台标题区显示。原始文件名只出现在折叠素材信息中。

### 6.2 分析入口

头部右侧依次显示：

1. 对白分析。
2. 画面分析。
3. 综合分析。
4. 素材信息展开/收起按钮。

按钮状态：

| 工具集 | 未分析 | 运行中 | 已完成 | 失败 |
| --- | --- | --- | --- | --- |
| 对白分析 | 可打开配置 | 可查看配置和状态 | 可查看或重新配置 | 可查看失败信息 |
| 画面分析 | 可打开配置 | 可查看配置和状态 | 可查看或重新配置 | 可查看失败信息 |
| 综合分析 | 依赖满足后可打开 | 可查看配置和状态 | 可查看或重新配置 | 可查看失败信息 |

综合分析依赖未满足时：

1. 按钮禁用。
2. `title` 和可见说明均提示「请先完成对白分析和画面分析」。
3. 不创建空 Attempt。

## 7. 可折叠素材信息

折叠区至少展示：

1. 原始文件名。
2. 源视频相对路径。
3. 时长。
4. 分辨率。
5. 横屏/竖屏方向。
6. 格式。
7. 文件大小。
8. 字幕识别状态。
9. 语言。
10. 最近更新时间。
11. 素材 ID。

默认收起，用户展开后不改变分析工作区宽度。

## 8. 三套分析结果 Tab

Tab 固定为：

```text
对白分析 | 画面分析 | 综合分析
```

每个 Tab 显示：

1. 独立状态。
2. 已有结果时显示片段数量。
3. 当前选中态。
4. 只读取本方案对应的产出物。

建议产出物边界：

```text
SessionOutput/json/srt_semantic_segments.json
SessionOutput/json/visual_semantic_segments.json
SessionOutput/json/composite_semantic_segments.json
```

不同 Tab 不得通过前端临时转换互相伪造结果。

## 9. 左侧片段列表

左侧区域统一命名为「片段列表」，具体列随 Tab 改变。

### 9.1 对白分析 Tab

每行至少显示：

1. 序号。
2. SRT / 对白文本。
3. 起止时间。
4. 片段标题或语义简介。
5. 可用性、待复核或过滤状态。

### 9.2 画面分析 Tab

纯画面结果不能伪装成 SRT。每行至少显示：

1. 序号。
2. 视觉片段标题或场景摘要。
3. 起止时间。
4. 场景、人物、动作或镜头变化摘要。
5. 可用性、待复核或过滤状态。

### 9.3 综合分析 Tab

每行至少显示：

1. 序号。
2. 综合片段标题。
3. 对白摘要。
4. 画面摘要。
5. 起止时间。
6. 关键词和可用性。

### 9.4 列表交互

1. 默认选中第一条结果。
2. 点击一行后只修改当前选择，不修改结果文件。
3. 当前行使用浅蓝色选中态。
4. 视频播放进度进入其他片段范围时，首版不自动改变选择；后续可增加时间轴联动。

## 10. 右侧视觉预览区

右侧固定为当前选中片段的证据视图。页面使用“中间片段列表 + 最右侧视觉栏”的双栏结构；视觉栏独立贯穿详情工作区，不嵌套在片段列表卡片内部。视觉栏至少包括：

1. 片段编号、标题和起止时间。
2. 源视频播放器。
3. 对应的全部 Keyframe 缩略图。
4. 当前 Keyframe 大图。
5. 视觉描述。
6. 人物、场景、动作、物体和镜头等结构化信息。
7. 可用、待复核、过滤及问题原因。

交互规则：

1. 选择片段后，视频跳转到片段开始时间。
2. 播放到片段结束时间后暂停。
3. 点击 Keyframe 后，视频跳转到 `keyframe_time`。
4. 没有 Keyframe 时显示明确空状态，不显示伪造图片。

## 11. 工具集配置抽屉

三套工具集共用抽屉框架，但配置和步骤相互独立。

首版抽屉展示：

1. 工具集名称和说明。
2. 当前 Task、Session 和素材源文件。
3. 工具步骤清单。
4. 输出目录说明。
5. 当前状态。
6. 关闭按钮。
7. 「运行工具集」占位按钮；真实执行未接入前必须禁用，不得伪造成功。

工具集建议说明：

| 工具集 | 首版步骤摘要 |
| --- | --- |
| 对白分析 | 音频/ASR、字幕 OCR 校准、SRT-Keyframe 对齐、对白语义拆分 |
| 画面分析 | Shot 检测、视觉证据提取、Keyframe 理解、视觉语义拆分 |
| 综合分析 | 读取对白结果、读取画面结果、边界融合、质量标注、综合片段索引 |

## 12. 页面状态

### 12.1 未分析

1. 默认进入对白分析 Tab。
2. 左侧显示「尚未生成对白分析结果」。
3. 右侧仍可播放原始视频，但 Keyframe 和视觉描述显示空状态。

### 12.2 运行中

1. 对应 Tab 和工具按钮显示运行中状态。
2. 已存在的旧结果继续只读展示。
3. 首版不实现真实轮询，仅保留状态结构和样式。

### 12.3 部分完成

1. 已完成 Tab 可以正常查看。
2. 未完成 Tab 显示各自空状态。
3. 只有对白和画面都完成后，综合分析入口才可用。

### 12.4 失败

1. 对应 Tab 显示失败原因区域。
2. 其他已完成结果不受影响。
3. 工具抽屉预留重新运行入口，但首版不执行。

### 12.5 加载和错误

1. 首次加载显示详情工作区骨架或轻量加载卡片。
2. API 失败显示错误说明和返回列表按钮。
3. 不显示虚构的片段、Keyframe 或分析描述。

## 13. 首版数据合同

详情接口继续使用：

```text
GET /api/media-library/{asset_id}
```

在素材基础信息之外增加：

```json
{
  "item": {
    "asset_id": "mla_xxx",
    "session_id": 51,
    "open_cut": {
      "task_id": 12,
      "status": "draft",
      "dialogue_status": "not_analyzed",
      "visual_status": "not_analyzed",
      "composite_status": "not_analyzed"
    },
    "analysis_results": {
      "dialogue": { "items": [] },
      "visual": { "items": [] },
      "composite": { "items": [] }
    }
  }
}
```

首版可以返回空结果数组，但 Task ID 和 Session ID 必须来自真实数据，不得由前端生成。

## 14. 独立模块边界

素材详情页继续位于独立模块：

```text
frontend/src/modules/mediaLibrary/
```

推荐拆分：

```text
detail/
  MediaLibraryDetailHeader.jsx
  MediaLibraryAssetInfo.jsx
  MediaLibraryAnalysisTabs.jsx
  MediaLibraryFragmentList.jsx
  MediaLibraryVisualPanel.jsx
  MediaLibraryToolDrawer.jsx
  mediaLibraryDetailModel.js
```

样式拆分：

```text
styles/mediaLibraryDetail.css
styles/mediaLibraryDetailHeader.css
styles/mediaLibraryDetailWorkspace.css
styles/mediaLibraryDetailDrawer.css
```

后端 OpenCut Task 使用独立表和 Repository，不依赖 `Analysis_V1`、`openclip_tasks` 或口播路由。

## 15. 首版验收标准

1. 从素材名称可以进入详情页，素材库导航保持高亮。
2. 标题只显示一次素材名称。
3. 页面显示真实 Task ID 和 Session ID。
4. 三个分析按钮均存在，点击对白/画面按钮可以打开对应配置抽屉。
5. 综合分析依赖未满足时处于禁用状态并说明原因。
6. 三个 Tab 可以切换，状态和片段数量互相独立。
7. 左侧结果区不伪造数据，无结果时展示准确空状态。
8. 右侧可以播放源视频，并具有 Keyframe、描述和结构化信息区域。
9. 素材信息默认收起，可以展开和收起。
10. 页面不提供 SRT 或分析结果编辑入口。
11. 详情页代码按组件和样式职责拆分，没有新的超大单文件。
12. 前端生产构建通过，页面无控制台错误。
